# 开发与修改指南

这份文档写给「下一次要加功能 / 修 bug 的人（或 AI）」。先读它，再动代码。

---

## 1. 项目是什么

本地运行的英文芯片手册阅读器：PDF.js 显示原文，中文搜索定位，段落/选中文字用本机模型或在线模型（智谱 / DeepL）翻成中文，位域表和表格用文字坐标结构化还原。

技术栈：Next.js 15 + React 19 + TypeScript + PDF.js；翻译运行时 = Python + CTranslate2 + SentencePiece（`.runtime/`，模型在 `models/argos-en-zh/`）。

## 2. 启动（每次开发都要）

```powershell

$env:Path="C:\Users\32700\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin;$env:Path"
```

## 4. 常见改动怎么做

### 加一个翻译引擎（比如阿里百炼 Qwen）

1. 复制 `src/lib/translation/online.ts` 改名，改端点/模型/key 文件名；
2. `src/app/api/translate/route.ts` 加一个 `provider === "qwen"` 分支（照抄 deepl 分支）；
3. `src/app/page.tsx` 的引擎下拉加 `<option value="qwen">`，`translationProvider` 的联合类型加上 `"qwen"`；
4. `src/app/api/model/route.ts` 暴露配置状态（照抄 `deepl: deeplConfig()`）；
5. 跑 `npx tsc --noEmit`，并用 `curl`/`node` 打一次 `/api/translate`。

### 改翻译质量

先分清是哪一类问题：

| 现象 | 改哪里 |
| --- | --- |
| 寄存器名/地址/数值被翻掉 | `protect.ts`（占位规则、`UPPER_WORDS` 白名单） |
| 术语错（登记器/标针/坦佩尔） | `terms.ts` 的 `OUTPUT_FIXES` |
| 目录页/短句乱翻 | `sanitize.ts` |
| 整段重复/乱码 | `quality.ts` |
| 模型本身质量差 | 换引擎（DeepL）或调 `online.ts` 里的系统提示词 |

### 改搜索命中

`src/lib/retrieval.ts`：先看 `termsForQuestion` 是否把中文扩成了正确的英文；再看打分权重（`strongHit`、`hasRegisterDefinition`、`frontMatterPenalty`）。词表在 `glossary.ts` 和 `datasheet/terms.ts`。

### 加 UI 功能

`page.tsx` 里已经有：搜索面板、译读面板、模型面板、位域表面板、表格面板、选中翻译面板。新面板照抄 `TablePanel.tsx` 的结构：一个 state 开关 + 一个 `<aside>` + 一段 CSS。

## 5. 用 AI 改 bug 的正确姿势

**不要**把整个项目丢给 AI 说“帮我看看”。按这个模板来：

```text
项目：D:\tool\芯片手册翻译器（英文芯片手册阅读器）
现象：<具体现象，例如：选中 "Chip Select" 点翻译，面板显示"内容过短，未翻译">
复现：启动 3010 → 打开 .samples/nm25q128.pdf → 第 8 页 → 选中表格单元格 → 点翻译
相关文件（只改这些）：src/lib/translation/sanitize.ts、src/app/page.tsx
约束：不要改 PDF 渲染；不要动 .runtime/models；改完跑 npx tsc --noEmit 和 npx eslint .
请先说明根因，再给最小改动。
```

3 条经验：

1. **贴现象 + 复现路径 + 文件名**，比贴代码更有效；
2. 让 AI **先说根因再改**，避免它顺手重构；
3. 改完必须自己跑 `tsc` / `eslint` / 对应测试脚本，AI 说“已修复”不算数。

已知的坑（AI 容易踩）：

- Next.js 用 `node next dev` 启动，不是 `npm run dev`；
- CTranslate2/SentencePiece 打不开非 ASCII 绝对路径，`translate_server.py` 里靠 `chdir` 规避，别改回去；
- 占位符格式必须是 `[[Zn]]`（`⟦⟧` 会被模型吃成 Q）；
- 目录页送进模型会幻觉（“诸法性相”），只能靠 `sanitize.ts` 挡；
- DeepL 不开放中国大陆注册，key 是 Free 计划（`:fx`）。

## 7. 已知未完成（按优先级）

1. **EXE 打包**：没有生成过安装包，也没在无 Node 环境验收；
2. **表格单元格切分**：跨行说明会串行，合并单元格会错列（矢量线方案已试过并回退，见 `outputs/表格解析-记录.md`）；
3. **位段选中翻译**：`Bits 26:24` 会被译成“第 26 章第 24 节”，需要结构化拦截；
4. **质量评分**：没有 20 段人工评分表，只有逐段样例；
5. **跨厂商泛化**：中文搜索已改善，但位域/表格解析仍偏 STM32 形态。

## 8. 交接验收（换人/换机器）

1. `npm install`；
2. `powershell -File tools\setup-runtime.ps1`；
3. 启动 3010，打开 `.samples/rm0008-en.pdf`，搜“GPIO 复用功能重映射寄存器”→ 应命中第 184 页 AFIO_MAPR；
4. 悬停段落 → 本机引擎出中文；
5. 引擎切 DeepL → 再悬停 → 译文质量更好（需要 `.deepl-key`）；
6. `node tools\e2e-api.mjs` 全绿。
