# 分族表格解析（第一版）

日期：2026-11-13
目标：把数据手册的表格按坐标还原成结构，先覆盖"引脚定义表 / 电气参数表"这一族。

## 实现

- `src/lib/datasheet/tables.ts`
  - `buildLines(spans)`：把文字层 span 聚成行；
  - `detectTables(lines, page)`：靠表头关键词（PIN / SYMBOL / DESCRIPTION / MIN / TYP / MAX / UNIT / PARAMETER…）识别表头，用表头单元格**左边缘**划列，逐行还原单元格；
  - `tableKind()`：区分引脚表 / 电气参数表 / 其它；
  - 同一逻辑行跨多根文本行时按"最左列有新内容才开新行"合并。
- `src/app/TablePanel.tsx`：页面右上「表格」按钮，列出本页识别到的表，支持切换、查看原文、**一键翻译说明列**（复用离线/在线 provider，占位保护照旧）。
- `PdfReader.tsx`：文字层渲染完成后把 span 坐标交给检测器，结果按页缓存。

## 实测（真实 PDF）

| 手册 | 页 | 识别结果 |
| --- | ---: | --- |
| NM25Q128（SPI Flash） | 8 | **引脚定义表**：SYMBOL / DESCRIPTION，7 行，`CS#→Chip Select`、`SCLK→Clock Input` 对齐正确 |
| NM25Q128 | 13 | 保护块表（Block / Sector / Address range / Lock Operation）与安全寄存器表被识别 |
| DS18B20（温度传感器） | 2 | **引脚表**：PIN / 8PIN SOIC / PIN TO92 / SYMBOL / DESCRIPTION，28 行 |
| ILI9341（显示驱动） | 22 | Pad 表（No. / Pad name / X / Y），50 行 |
| RM0008（参考手册） | 184 / 250 | 不是表格形态，面板提示"没有识别到表格"（位域表仍由「位域表」按钮处理） |

## 已知不足

1. **跨行说明会串到上一行**：符号在表格里垂直居中时，说明的第一行和上一个符号同一 y，会被合并到上一行（截图中 SCLK 行混入了 SI/SIO0 的说明）。
2. **跨页表**只处理当前页；表头在上一页的续表识别不到。
3. **合并单元格**（如 "PIN" 跨两列）会多出一列，数据列因此错位一列（DS18B20 表头 5 列、数据 4 列）。
4. 表格内文字还没有做"单元格级保护 + 术语校正"，翻译说明列时仍可能把引脚名译成中文（有占位保护兜底）。

## 下一步

- 用"单元格边框线"（PDF 的 vector 路径）替代纯文本坐标，可一次性解决跨行串行和合并单元格；
- 跨页续表：记住上一页的表头，下一面页首继续；
- 电气参数表加"数值/单位"列的类型化（min/typ/max 数值不改写、单位保留）。

## 矢量线条版实验（2026-11-13，未采用）

按原计划实现了基于 PDF 矢量路径的网格还原（`pathsToSegments` + `buildTablesFromGrid` + 与文字框混合的 `refineTableWithGrid`），实测后**回退**，原因有数据：

| 手册 | 页 | 文本版 | 线条版 |
| --- | ---: | --- | --- |
| NM25Q128 | 8 | 7 行，`CS#→Chip Select` 正确 | **同样 7 行**，SCLK 行仍混入 SI/SIO0 的说明 |
| ILI9341 | 22 | 50 行 Pad 表 | 50 行，无改善 |
| DS18B20 | 2 | 28 行 | **反而变成 2 行**（表头落到数据行，网格被裁错） |
| NM25Q128 | 13 | 2 个表 | 0 个（页内线条把整页连成一张大网格，超出尺寸上限被拒） |

根因：**这些 PDF 的表格没画完整网格**。

- NM25Q128 第 8 页只有「外框 + 一条列分隔竖线」，行与行之间没有横线 → 按线条切不出行；
- DS18B20 的横线贯穿多行 → 网格把多行并成一行；
- ILI9341 的 Pad 表画了完整网格，所以线条版和文本版结果一致。

结论：**线条只适合"画满格"的表**，而数据手册里相当一部分表只画外框和列线。要稳定还原需要：

1. 单元格边界推断：把"只有横线"或"只有竖线"的表补全（按文字基线聚类行高）；
2. 或引入成熟表格抽取库（Camelot/Tabula 那类 ruling + 文本对齐实现）；
3. 跨页续表单独处理。

在做到这些之前，文本坐标版仍是默认，面板里也标了"结构由文字层坐标还原"。实验代码已删除，避免留下未接入的 `grid.ts` 死代码；结论与数据留在本节。
