# 泛化实测：换一本手册还能不能翻

日期：2026-11-13
测试对象（全部来自本机资料盘，英文原版）：

| 文件 | 页数 | 类型 |
| --- | ---: | --- |
| `rm0008-en.pdf`（ST 官网 Rev 21） | 1136 | STM32 参考手册（当前样本） |
| `rm0008-v20.pdf`（你给的 V20 英文版） | 1134 | 同一本手册的旧版本 |
| `ili9341.pdf` | 239 | ILI9341 显示驱动 IC 数据手册 |
| `nm25q128.pdf` | 92 | SPI NOR Flash 数据手册 |

## 结论先说

**同一本手册的另一个版本：基本一致。**
**换一颗芯片：能出中文，但离“翻译无误”还很远。**

| 能力 | RM0008 V20 | ILI9341 | NM25Q128 | DS18B20 |
| --- | --- | --- | --- | --- |
| 打开 / 建索引 | 正常 | 正常 | 正常 | 正常 |
| 段落翻译（散文） | 可用 | 可用 | 可用 | 可用 |
| 位域表解析 | 可用 | **0 行** | **误报 24 行** | **0 行** |
| 中文搜索 | 可用 | **3 个查询全 0 命中** | 3 查中 1 中 | **3 个查询全 0 命中** |
| 目录/点线页 | 正常 | 会翻出目录点线 | **翻出目录点线并产生乱码译文** | 正常 |

## 具体证据

### 1. 同一手册不同版本（V20）

1134 页 vs 1136 页，文字层、位域解析、搜索行为与当前样本一致。这属于“同一份材料的另一版”，不构成泛化考验。

### 2. 中文搜索基本失效

用真实应用接口跑（`/api/documents` + `/api/ask`）：

```
ILI9341：显示初始化命令 → 0 条；内存写命令 → 0 条；如何设置显示窗口 → 0 条
DS18B20：温度转换命令 → 0 条；读取温度 → 0 条；分辨率设置 → 0 条
NM25Q128：写使能命令 → 0 条；状态寄存器 → 8 条；扇区擦除 → 0 条
```

原因很明确：`src/lib/retrieval.ts` 里的 16 条意图正则和 `glossary.ts` 的词表都是按 STM32 参考手册写的（RCC/GPIO/AFIO/USART…），换厂商等于没有词表。

### 3. 位域表解析只认 STM32 的写法

- ILI9341：寄存器按「命令 + 参数表」组织（`2Ch`、`D/CX`、`RWX`），没有 `Bits x:y` 行 → 0 行；
- DS18B20：命令是字节码表（`44h`、`BEh`），也没有位段 → 0 行；
- NM25Q128：状态寄存器表里恰好有类似“位”的写法 → 匹配到 24 行，但内容是表格单元格碎片，属于**误报**，比不解析更危险。

### 4. 段落翻译：散文还行，目录点线会崩

DS18B20 正文（可读）：

> Information is sent to/from the DS18B20 over a 1-Wire interface…
> → 信息通过1线接口发送到/从DS18B20，这样只需要从中央微处理器连接到DS18B20的一条线（和地面）。

NM25Q128 目录页（点线 + 页码）直接幻觉：

> FEATURES ....................
> → 诸法性相. 皆有四谛.
>
> RESET .......................
> → 清·乾隆"通志"卷七十二·人物志.

这不是模型“翻错”，是**输入本身就是噪声**（几百个点号 + 页码），模型在乱码上下文里自由发挥。必须在送翻前过滤目录/索引页。

## 所以“能不能翻译无误”的回答

- 同一本手册换版本：能，行为和现在一致。
- 换厂商/换芯片类型：**不能**。当前只保证“PDF 能打开、段落能给中文”，不保证术语正确、结构正确、搜索找得到。

## 要真正泛化，缺的是这四件事（按优先级）

1. **送翻前的页面过滤**：识别目录、索引、点线页、纯表格页，跳过或按单元格处理，杜绝“诸法性相”这种幻觉。
2. **通用双语术语层**：寄存器 / 位 / 命令 / 状态 / 地址偏移 / 复位值 / 使能 / 保留……不绑定 STM32；再叠一个厂商词表（ST、ILI、Winbond、Maxim…）。
3. **实体索引替代意图正则**：从文字层抽 `0x..` 地址、`XXh` 命令码、`Bits x:y`、`Offset` 表头，建索引；中文查询先映射到实体类型再匹配，而不是猜整句意图。
4. **表格解析器分族**：STM32 位域表、显示 IC 命令参数表、Flash 状态寄存器表各一套，按文档特征自动选。

这四件都不需要换模型，属于工程结构问题。
